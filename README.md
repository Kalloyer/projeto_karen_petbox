# PetBox Club

Landing page responsiva da PetBox Club, focada em assinatura mensal para pets com personalização por perfil.

## Tecnologias

- React
- Vite
- CSS
- Lucide React

## Identidade visual

Paleta principal aplicada:

- Amarelo destaque: `#FFC93C`
- Rosa/coral vibrante: `#FF6B6B`
- Azul vivo: `#4D96FF`
- Verde menta: `#6BCB77`
- Creme de fundo: `#FFF9F1`
- Marrom escuro para texto: `#5A3825`

## Seções da landing

- Início
- Como funciona
- Planos
- Benefícios
- Contato
- Modal de personalização da box

## Execução local

```bash
npm install
npm run dev
```

URL local obrigatória:

```bash
http://localhost:5175
```

## Build de produção

```bash
npm run build
```

## Publicação na Vercel

Configuração recomendada:

- Framework Preset: `Vite`
- Install Command: `npm install`
- Build Command: `npm run build`
- Output Directory: `dist`
